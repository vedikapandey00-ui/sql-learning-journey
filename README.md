# SQL Learning Journey

Welcome to my SQL learning journey.

I am learning SQL from the basics through hands-on projects, with a focus on business and financial data analysis.

## Day 01 — Retail Sales Analysis

For my first SQL practice project, I created a small retail sales dataset and analyzed it using PostgreSQL.

### Business Questions

* What is the total revenue?
* What is the average order value?
* Which products generate the most revenue?
* Which categories generate the most revenue?
* Which cities generate the most revenue?
* Who are the highest-value customers?
* How does revenue change over time?

### SQL Concepts Practiced

* SELECT
* WHERE
* ORDER BY
* LIMIT
* SUM()
* AVG()
* COUNT()
* GROUP BY
* Basic date analysis
* Calculated columns

### Tools Used

* PostgreSQL
* pgAdmin
* SQL
* GitHub

### About This Project

This is a beginner practice project created as my first step toward learning SQL for data analysis.

The dataset is a small practice dataset and is not intended to represent real company data.

## What's Next?
